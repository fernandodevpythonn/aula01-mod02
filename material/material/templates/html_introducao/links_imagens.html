Links e Imagens

Criar links e inserir imagens no HTML com Flask.

Links (âncoras)

Um link é criado com a tag <a> e o atributo href:

<a href="https://www.senacrs.com.br/home" target="_blank" rel="noopener">Visitar Senac</a>

Isso cria um link clicável que abre em nova aba para www.senacrs.com.br.

Exemplos de diferentes tipos de target:

  • _self - abre na mesma aba
  • _blank - abre em nova aba
  • _parent - abre no frame pai
  • _top - abre no documento inteiro
  • minha_aba - abre sempre na mesma aba nomeada

Imagens

Uma imagem é inserida com a tag <img>:

O atributo alt fornece uma descrição acessível, e o src busca a imagem python.gif na pasta static/imagens.

HTML

HTML com link e imagem:

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Links e Imagens</title>
</head>
<body>
    <a href="https://www.senacrs.com.br/home" target="_blank" rel="noopener">Visitar Senac</a>
    <br>
    <img src="{{ url_for('static', filename='imagens/python.gif') }}" alt="Python Logo">
</body>
</html>
