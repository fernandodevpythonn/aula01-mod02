Formulários HTML com Flask

Aprenda a criar formulários em HTML e capturar dados no Flask.

Formulário Básico

Um formulário simples com nome e email:

<form action="/resultado" method="POST">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome" required>
    <br>
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>
    <br>
    <input type="submit" value="Enviar">
</form>

Formulário Avançado

Inclui textarea, select, radio e checkbox:

<label for="mensagem">Mensagem:</label>
<textarea id="mensagem" name="mensagem" rows="4" cols="50"></textarea>

<label for="curso">Curso:</label>
<select id="curso" name="curso">
    <option value="python">Python</option>
    <option value="html">HTML</option>
    <option value="flask">Flask</option>
</select>

<label>Sexo:</label>
<input type="radio" id="masc" name="sexo" value="masculino"><label for="masc">Masculino</label>
<input type="radio" id="fem" name="sexo" value="feminino"><label for="fem">Feminino</label>

<label>Hobbies:</label>
<input type="checkbox" id="ler" name="hobbies" value="ler"><label for="ler">Ler</label>
<input type="checkbox" id="jogar" name="hobbies" value="jogar"><label for="jogar">Jogar</label>

Explicação dos campos

  • <label>: define o texto explicativo do campo.
  • <input type="text">: campo para texto simples.
  • <input type="email">: campo que valida email.
  • <textarea>: área de texto maior.
  • <select> com <option>: menu suspenso.
  • <input type="radio">: escolha única.
  • <input type="checkbox">: múltipla escolha.
  • required: torna o campo obrigatório.
  • <input type="submit">: botão para enviar o formulário.
