página de links

A tag A é utilizada para a criação de links em uma página
é utilizada no dia a dia para criar atalhos para outras páginas do sistema

Diferença entre Link externo e Link interno:

Link interno ocorre quando há utilização de links para páginas internas do sistema

Links externos ocorrem quando a tag a é utilizada para sistemas externos

Exemplos:Link externo: Canva

Link Interno: Página inicial
